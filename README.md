# Carlos Eduardo Krueger

**Software Engineer with 8 years leading logistics, budget and procurement operations**

I spent 8 years as a Brazilian Army logistics officer, and in almost every role I ended up building a tool to fix the problem in front of me. Today I build the software and AI for the kind of operations I used to run: budgets, contracts, fleets and supply.

On Operation Acolhida, a humanitarian mission run with UN agencies, I brought AI into the finance section. With the team I built an assistant and a dashboard that replaced 42 spreadsheets. Reports that took 1 to 2 days now come back in seconds, and about 100 people still use it.

**Focus:** AI automation for operations, LLM applications with guardrails, and backend engineering.

**Stack:** TypeScript, JavaScript, Node.js, Java (Spring Boot, Spring AI), Python, SQL and PostgreSQL, REST and GraphQL.

**AI:** LLM apps, tool calling, RAG, agents, prompt engineering, Claude and Claude Code.

Based in Brazil (UTC-3). Open to remote roles in AI automation, solutions and implementation engineering.
